# FK Vojvodina — sajt

Next.js 16 (App Router, TypeScript, CSS Modules) implementation of the redesign in `design_handoff_fkvojvodina_nextjs/`.

```bash
npm install
npm run dev     # http://localhost:3000 → /lat
npm run build
```

Languages: `/lat` (default), `/cir`, `/en`. Data in `src/lib/data/` is illustrative and must be replaced by the CMS / league API.
